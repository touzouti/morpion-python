# Morpion en Python

Jeu de morpion avec une interface graphique réalisée avec Tkinter.

## Fonctionnalités

- Grille de 3 × 3
- Alternance entre les joueurs X et O
- Détection du gagnant
- Détection du match nul
- Bouton pour recommencer une partie

## Prérequis

- Python 3
- Tkinter

## Lancer le jeu

Dans le dossier du projet, exécuter :

```powershell
python .\main.py
```
